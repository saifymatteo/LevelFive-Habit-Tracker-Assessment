Code changes need a restart The backend Dockerfile runs uvicorn without --reload. After editing Python: docker compose up --build backend. After editing frontend: docker compose up --build frontend (full npm build each time — slow). For fast frontend iteration: cd frontend && npm install && npm run dev — Vite's proxy sends /api to localhost:8000.

How work is expected to happen here (repo conventions)

  • Features are spec'd in .scratch/<feature-slug>/spec.md, with one ticket per file in .scratch/<feature-slug>/issues/01-<slug>.md and a Status: line (see docs/agents/issue-tracker.md).
  • Domain vocabulary would live in CONTEXT.md, decisions in docs/adr/ (see docs/agents/domain.md) — neither exists yet; creating them when you make a real decision is a plus, not a requirement.
  • There are no tests in the repo. Adding even a smoke test for your change is differentiating.
  • The git repo has no commits — an early git add -A && git commit -m "baseline" gives you a diff to show your work.
