# Assessment format confirmed: live coding, 60 minutes

User confirmed the Friday assessment is a live coding session with a 1-hour allocation. This rules out take-home depth (no time for tests, docs, or refactors) and reframes success: one small end-to-end change, done fluently, narrated confidently. Speed of verification matters — `/docs` for backend, `npm run dev` for frontend, psql for data checks.

**Implications:** Lesson 5 becomes a timed dress rehearsal of exactly that format (spec file per repo convention → endpoint + UI → demo). The bug-hunt lab (L4) tightens to the highest-probability planted issues rather than the full catalog. Environment must be running before the hour starts; a pre-flight checklist becomes lesson content.
